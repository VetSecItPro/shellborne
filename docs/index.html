What it promises

Sessions survive

Your agents keep running if the app quits, crashes or updates.

Contained

One misbehaving pane cannot take the others down with it.

Exact

What you type reaches the agent exactly as you sent it.

Local

No account, no analytics. Nothing leaves your Mac unless you choose.

Honest

If it is not sure what a session is doing, it says so.

How it is built
>_ code: public on GitHub from the first commit >_ agents: write much of it, and that is said plainly >_ tests: written first, and every merge waits on them >_ people: a person approves every change before it merges
